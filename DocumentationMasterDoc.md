# IdealBet - Sports Betting Analysis Platform
## Software Requirements Specification (SRS)

### 1. Introduction
IdealBet is a sophisticated sports betting probability calculator and analysis platform that combines real-time odds, historical data, and advanced algorithms to provide accurate predictions for sports betting. The platform focuses on NBA betting but is designed to be extensible to other sports.

### 2. System Overview
#### 2.1 Purpose
The purpose of IdealBet is to provide bettors with data-driven insights and predictions for sports betting, helping them make more informed decisions through advanced analytics and real-time data processing.

#### 2.2 System Features
- Real-time odds analysis from multiple sportsbooks
- Advanced probability calculation algorithms
- Team and player statistics analysis
- Custom betting strategies
- Fantasy betting features
- User authentication and profile management
- Saved bets tracking
- AI-powered betting assistant

### 3. Technical Architecture
#### 3.1 Frontend
- **Framework**: Next.js with TypeScript
- **Styling**: Tailwind CSS
- **Animations**: Framer Motion
- **State Management**: React Hooks
- **Authentication**: NextAuth.js with Google OAuth

#### 3.2 Backend
- **API Integration**: 
  - The Odds API for sports betting odds
  - NBA Stats API for player and team statistics
- **Database**: Firebase/Firestore
- **Hosting**: Vercel
